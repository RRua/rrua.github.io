# rrua.github.io

Personal page of Rui Rua, built with Jekyll and the [AcademicPages](https://github.com/academicpages/academicpages.github.io) template.

## Where to edit

- `_pages/` - the pages (home, publications, software, teaching, service, CV).
- `_data/publications.yml` - the publication list. Set `selected: true` to show an entry on the home page.
- `_data/news.yml` - the news list. The home page shows the first 5 entries.
- `_data/navigation.yml` - the top menu.
- `_sass/_custom.scss` - site-specific styles.

## Run locally

```
bundle install
bundle exec jekyll serve
```
